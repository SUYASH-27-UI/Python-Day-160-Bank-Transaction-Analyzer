# Bank Transaction Analyzer – Python Day 160

## Description
A Python project that reads bank transactions from a CSV file and generates a financial summary.

## Features
- Reads transaction records from CSV
- Calculates total income and expenses
- Calculates remaining balance
- Displays category-wise expenses
- Finds the highest spending category
- Handles missing files and invalid data

## Technologies
- Python
- CSV Module
- Collections Module

## Files
- `transaction_analyzer.py`
- `transactions.csv`

## How to Run
```bash
python transaction_analyzer.py
```

## Concepts Used
File Handling, CSV, Dictionaries, Data Analysis, Exception Handling.
